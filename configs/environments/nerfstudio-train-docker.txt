Local hardware boundary
  WSL memory limit is about 7.6 GiB. Caching all 1,553 source images at
  1080x1920 RGB uint8 would require about 9.0 GiB before process/model overhead.
  The local run is therefore an explicitly labeled 0.5 camera-resolution
  variant. It does not rewrite the source images and must not be reported as the
  original full-resolution experiment. A strict full-resolution run should use
  a machine with at least 32 GiB RAM.
